## E2 — order-invariance

- **Exhaustive, all runs of length <= 14** (4674890 reachable
  transitions): on every transition `s --ev--> s'` we verified
  `ev not in event_set(s)` and `event_set(s') = event_set(s) ∪ {ev}`,
  and on every reached state `reconstruct(event_set(s)) = s`, where
  `event_set(s) = {link p : p in U} ∪ {link c(t), resolve c(t) : t in T composite}`
  and `reconstruct` rebuilds `(T,U)` from an event set alone.  By
  induction along any run this proves: the executed event SET equals
  `event_set(final state)` and the set determines the state — i.e. the
  reached state is a function of the set of executed events, for every
  run of length <= 14, with zero violations.  (No event ever repeats
  within a run, so runs are sequences of distinct events.)
- **Random beyond**: 1000 trials; each trial draws a uniformly
  random run of length 40, then executes a fresh random valid
  re-scheduling of the same event set and compares final states.
  Mismatches: **0** (seed 213).

This is the SPEC Q1 shape: runs are linear extensions of one causal
order; only the set (equivalently the causal poset filter) is real.

## E4 — grading divergence

Folds per tree: `depth` (max nesting), `size` (leaf count), `gen`
(minimal lockstep generation: first stage k of G_0={a,b},
G_{k+1}=G_k ∪ pairs(G_k) containing the tree).

- Verified for all 44 trees of size <= 6: **gen(t) = depth(t)**
  (the lockstep stage number is exactly the nesting depth), so the
  operative divergence is depth-vs-size.
- Lockstep layer cardinalities |G_k|, k=0..5: [2, 3, 5, 12, 68, 2280]
  (recurrence |G_{k+1}| = C(|G_k|,2) + 2 — doubly exponential).
- On all 9 trees of size <= 4 the folds are locked in the bijective
  correspondence `size = depth + 1` (= gen + 1): the five level-<=2
  objects a, b, (ab), (a(ab)), (b(ab)) and the four size-4 chains.
- **First divergence witness** (trees ordered by size, then canonical
  bracket string):

  > ((ab)(a(ab)))  (size 5, depth 3, lockstep gen 3): first tree where folds diverge -- depth=3 had always co-occurred with size=4 on all earlier trees, here size=5

  The witness **((ab)(a(ab)))**: size 5 but depth 3 — the first tree whose two
  children are both composite and of different depths, i.e. the first
  place the chain-pattern (each level adds one leaf) breaks.  It lies
  immediately past the five level-<=2 objects, as SPEC Q2 predicts.

- First strict order-reversal between depth and size: (a(a(a(ab)))) (depth 4, size 5) vs ((a(ab))(b(ab))) (depth 3, size 6)
  (depth and size do not merely decouple — they eventually order
  trees oppositely, so no monotone rescaling reconciles them).

### Rank-function failure in D

An element whose lower covers sit at different heights (heights cannot
be a rank function; searched over all events with composite size <= 8,
ordered by height, then size, then canonical repr):

- **Under the task-stated cover relations**: link{(a(ab)),(ab)} at height 4 (composite ((ab)(a(ab)))); stated lower covers at heights [('resolve{a,b}', 1), ('resolve{(ab),a}', 3)]
  — the link event of the SAME witness tree ((ab)(a(ab))).
- Caveat found by the closure computation: stated relation resolve{a,b} < link{(a(ab)),(ab)} is a chord: resolve{a,b} < resolve{(ab),a} < link{(a(ab)),(ab)}.
  So in the transitive closure that stated relation is a chord, not
  a cover ((ab) occurs inside (a(ab)), and indeed inside every
  composite, so resolve{a,b} sits below resolve{a,(ab)}).
- **Under the true covers of the transitive closure**: link{(a(ab)),(a(b(ab)))} at height 6 (composite ((a(ab))(a(b(ab))))); true lower covers at heights [('resolve{(ab),a}', 3), ('resolve{(b(ab)),a}', 5)]
  — composite ((a(ab))(a(b(ab)))), size 7: the first pair of composite
  children that are subterm-incomparable AND of different depths.
  Either way a rank function fails strictly above the level-2 zone, at
  a computable first witness; heights exist, ranks do not (SPEC Q2).
